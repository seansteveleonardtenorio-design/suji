# Palawan GIS Explorer

A beginner-friendly, frontend-only GIS learning project built with HTML, CSS, JavaScript, Leaflet, and OpenStreetMap.

## Features

- Interactive street map initially centered near Puerto Princesa, Palawan
- Place search (limited to Palawan-focused searches)
- Click the map to inspect latitude and longitude
- Save named markers with optional notes
- Store markers in browser `localStorage` (no database)
- Copy coordinates
- Use device geolocation if the user grants permission
- Measure straight-line distance between two points
- Responsive layout for desktop and mobile

## Project files

- `index.html` — page structure and library links
- `style.css` — visual design and responsive layout
- `app.js` — map, search, marker, coordinate, geolocation, and distance tools

## How to run

### Option A: Open the file
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Keep the device connected to the internet.

Some browsers restrict location and clipboard features on `file://` pages. If so, use Option B.

### Option B: Run a local server (recommended)
If Python is installed:
1. Open a terminal or command prompt in this project folder.
2. Run `python -m http.server 8000`
3. Open `http://localhost:8000` in your browser.

If using VS Code, you can also use a local development server extension such as Live Server.

## APIs, keys, and internet requirements

- **No API key is required** for this basic version.
- Leaflet is loaded from the unpkg CDN.
- Map tiles come from OpenStreetMap's public tile service.
- Place search uses the public Nominatim geocoding service.
- Internet access is required for map tiles, library downloads, and place search.
- The map includes required OpenStreetMap attribution.

### Responsible usage
Public OpenStreetMap tile servers and Nominatim are shared community services with usage policies and rate limits. Avoid repeated automated searches or high-volume use. For a public production website, review the current policies and consider a dedicated tile/geocoding provider. If using a different provider, follow its terms and display any required attribution.

## Storage and privacy

Saved markers stay in this browser's local storage on this device. They are not synced to other devices and are not sent to a database. Clearing browser site data may remove them. The geolocation button asks the browser for permission; the coordinates are used to show your location on the map and are not uploaded by this app. Map and search requests do contact their respective external services.

## Notes / limitations

- This is a learning demo, not an official navigation, surveying, emergency, or hazard-mapping tool.
- Distance measurement is a straight-line estimate between two points, not road distance.
- Search results depend on OpenStreetMap/Nominatim data coverage and may not always be exact.
- Keep the Leaflet and OpenStreetMap attribution visible if modifying the interface.
